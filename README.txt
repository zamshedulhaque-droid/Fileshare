FastShare - খোলার নিয়ম
1. Android Studio (Koala+) এ এই ফোল্ডারটি Open করুন, Gradle Sync হতে দিন।
2. দুটি আসল ফোনে (এমুলেটরে Wi-Fi Direct চলে না) Run করুন।
3. একটিতে "গ্রহণ করুন", অন্যটিতে "পাঠান" -> ফাইল বাছাই -> তালিকা থেকে রিসিভার ট্যাপ।
4. রিসিভ করা ফাইল: Android/data/com.fastshare/files/Download/
